# reference-plugin

@AGENTS.md

`AGENTS.md` is canonical: how to build pages with the plugin UI kit, and the
live loop. The loop is also the `develop-live` skill, under
`.claude/skills/`, for when a session is asked to change the plugin and see
it running. `CLAUDE.local.md` and `.claude/settings.local.json` are one
person's own, and git-ignored.
